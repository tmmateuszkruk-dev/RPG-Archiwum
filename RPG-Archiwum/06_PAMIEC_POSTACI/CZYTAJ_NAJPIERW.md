# Pamięć postaci C1–C13

118 kart, stan C13-M1029. Zachowane wcześniejsze fakty; przyrost C13 nie kasuje historii. Każda karta osobno w karty/. Indeks wzmianek obejmuje wszystkie części, ale nie jest dowodem wiedzy, obecności ani kanoniczności. Sprawdź 09_REJESTR_KOREKT i fragment źródłowy przed reakcją zależną od przeszłości.

Zapytanie z katalogu RPG-Archiwum:

```bash
python 06_PAMIEC_POSTACI/query_memory.py 06_PAMIEC_POSTACI hermiona --term naszyjnik --archive 01_ARCHIWA_CZATY/scalone/01_ARCHIWUM_CZAT_1-13_SCALONE.txt
```

Parametr --at C12-M1109 ogranicza czas; --offset i --limit stronicują wyniki. Synteza jest selektywna, nie obietnicą opisania każdej wypowiedzi. Dla dawnych scen rekonstruuj wiedzę w danym momencie.
